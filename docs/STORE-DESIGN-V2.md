# لغة «الوثيقة» — خطة تصميم المتجر v2

> **المرجع**: لقطة صفحة الدفع (`إتمام الطلب`) المرفقة.
> **الهدف**: نقل لغة اللقطة إلى كامل مجموعة `(store)` مع الحفاظ على الخلفية الأساسية وهوية البراند (الألوان والخطوط).
> **ما لا يتغيّر**: الأرضية `royal-navy`، الذهبي `#cd9e61`، الرملي `#f6e6d6`، الخطوط، النسخ من `messages/*.json`، الاتجاه RTL.

---

## 1. ما تقوله الصورة — قياس لا انطباع

اللقطة 1197×785، مأخوذة بدقة ~1.5×. القيم بعد التطبيع إلى 1×:

| العنصر | في اللقطة (px) | 1× | التوكن المقابل |
|---|---|---|---|
| أرضية الصفحة | `#0A1628` | — | `--color-royal-navy` ✓ |
| سطح اللوحة | `#0F1B2B` | — | `sand` بشفافية **2%** فوق الأرضية |
| حدّ اللوحة | `1px #262F3C` | 1px | `sand` **12%** |
| الفاصل الداخلي | `1px #262F3C` | 1px | نفس الحدّ |
| حشوة اللوحة | 48 | **32** | `px-8 py-12` |
| عرض اللوحة | 1008 | 672 | `max-w-2xl` |
| عنوان الصفحة | غلاف 58 | 36 | `text-4xl` ذهبي، **خارج** اللوحة |
| عنوان القسم (`الدفع`) | غلاف 32 | 18–20 | `text-h3` رملي |
| قيمة مميّزة (`850 د.إ`) | 24 | 24 | ذهبي (التمييز باللون) |
| تسمية خفيفة (`الإجمالي`) | `#9A9591` | — | `sand` **60%** → تباين 5.8:1 ✓ |
| تسمية أخفت (الإجمالي الصغير) | `#777778` | — | `sand` **47%** → تباين 3.9:1 ✗ |
| الحقل | 78 | **52** | `h-[52px]` |
| تعبئة الحقل | `#0C1829` | — | `royal-navy` **60%** فوق اللوحة (غائر) |
| حدّ الحقل | `#3B414C` | — | `sand` **20%** |
| الزوايا | 0 | **0** | `rounded-none` (حتى الحقل) |
| صف الإجراء | 86 | **56** | `h-14` |
| الزر الأساسي | 783 | 522 | `flex-1` |
| الفجوة بين الزرّين | 17 | 12 | `gap-3` |
| الزر الثانوي | 112 | 75 | بحدّ شعري، نفس الارتفاع |
| الفجوة حقل ← إجراء | 84 | 56 | مساحة يحتلّها الإجمالي الصغير |

**ملاحظة مهمة**: هذه القيم هي **نفس** توكنز صفحة الدفع الحالية عندنا (`bg-sand/[0.02]`، `border-sand/10`، `p-8`، `inputClass` القديم `bg-royal-navy/60 border-sand/20`). أي أنّ اللغة موجودة في المشروع بالفعل — لكن صفحات المتجر الجديدة (المراحل 2–4) انحرفت عنها إلى بطاقات ورقية رمليّة وحدود منقّطة.

## 2. القواعد الثمانية المستخرجة

1. **سطح واحد لكل مهمة.** صفحة = لوحة واحدة بحدّ شعري واحد. لا بطاقات داخل بطاقات، لا ظلال، لا تدرّجات.
2. **محوران فقط.** كل شيء يبدأ وينتهي على حدّي الحشوة (البداية/النهاية). لا عناصر عائمة في الوسط.
3. **فاصل شعري واحد.** 1px، بلون `sand/12`، بعرض الحشوة الكامل، يفصل الكتل المنطقية — **لا حدود منقّطة** ولا زخارف.
4. **ثلاثة مستويات نصّية داخل اللوحة**: عنوان قسم (رملي)، قيمة مميّزة (ذهبي)، تسمية (رملي 60%). لا شيء فوق ذلك.
5. **التمييز باللون لا بالوزن.** لا `font-bold` داخل اللوحة. الذهبي يقول «هذا الرقم المهم».
6. **الحقول غائرة.** أغمق من اللوحة بدرجة، بحدّ 20%، بلا ظل داخلي.
7. **صف إجراء واحد.** أساسي مملوء يتمدّد + ثانوي بحدّ شعري بنفس الارتفاع، على نفس السطر (ينزلان فوق بعضهما على الجوال).
8. **نقص الزخرفة = فخامة.** الفراغ داخل اللوحة جزء من التصميم (56px قبل صف الإجراء).

**ما يُمنع صراحةً**: خطوط `<hr>` منقّطة، `rotate` على البطاقات، حشوات رمليّة (`bg-sand`) كخلفيات، أيقونات زائدة، `tracking-wide` على نص عربي، `font-bold` داخل اللوحة، وشارات ملوّنة.

## 5. `/products` — الشريط الاحترافي (الأولوية)

### 5.1 الشكل

```
سجل الإصدارات                                        ← h1 ذهبي 36، على الأرضية
سطر واحد: ما يفعله هذا السجل                          ← رملي/60

┌──────────────────────────────────────────────────────────┐
│ الكل 24   عطور 8   بخور 3   مجوهرات 4   أقمشة 2  …       │ ← تبويبات 48px
├══════════════════════════════════════════════════════════┤ ← خطّ ذهبي 2px تحت النشط
│ [⌕ ابحث في السجل…………]                        [الترتيب ▾] │ ← صف استعلام 52px
├──────────────────────────────────────────────────────────┤
│ ١٧ قطعة · صفحة ١ / ٢                       [مسح الفلاتر] │ ← سطر نتائج 14px
└──────────────────────────────────────────────────────────┘

المجموعة والحضارة ↓ صفّ ثانوي من روابط نصية، لا تبويبات
```

- **النوع** يصبح التنقّل الأول (تبويبات) — لأن التصفّح يبدأ بالنوع.
- **الحضارة/المجموعة** تصبح سطرًا ثانويًا (نص + فاصل `·`)، بعيدًا عن منافسة التبويبات.

### 5.2 مواصفات التبويبات

```tsx
<Link
  href={…}
  aria-current={active ? "page" : undefined}
  className={`relative flex h-12 shrink-0 items-center gap-2 font-primary text-base
    transition-colors duration-200 after:absolute after:inset-x-0 after:-bottom-px
    after:h-0.5 ${active
      ? "text-gold after:bg-gold"
      : "text-sand/70 after:bg-transparent hover:text-sand"}`}
>
  {label}
  <span className="font-secondary text-micro tabular-nums text-sand/50">{count}</span>
</Link>
```

- الحاوية: `flex overflow-x-auto border-b border-[var(--store-rule)]` + `scroll-snap-type: x proximity`، بلا `wrap`.
- **تلاشي الحافّة** على الجوال بـ`mask-image` (ليس سكريماً كحلياً فوق صورة).
- `min-height: 48px` لكل تبويب، مسافة 32px بينها (`me-8` منطقي).
- العدّاد `text-micro` بـ`tabular-nums` حتى لا ترتجف الأرقام عند التبديل.
- مؤشّر منزلق (اختياري): عنصر مطلق واحد يتحرّك بـ`translateX` عند التبديل (200ms، `ease-out-expo`).

### 5.3 البحث

نموذج `GET` (يعمل بلا JS): حقل 52px + زر إرسال 44×44 داخل الحقل عند النهاية، وأيقونة `⌕` عند البداية.
مع `hidden inputs` للحضارة/المجموعة/النوع/الترتيب حتى لا تُلغى الفلاتر عند البحث.

### 5.4 الفرز

`<select>` أصلي بتصميم البراند (بلا JS للفتح، يعمل على الجوال):

```
الأحدث · السعر: من الأدنى · السعر: من الأعلى
```

يلزمه مكوّن عميل صغير `SortSelect` يستدعي `router.push` عند `onChange` (5 أسطر).

### 5.5 الشبكة

لا بطاقات مملوءة. كل قطعة = «لوحة» بلا إطار، فوقها خطّ شعري واحد يحمل رقم الإصدار:

```
───────────────────────────────  ← خطّ شعري + «N° 04» بحجم 12 ذهبي/70 عند النهاية
┌─────────────────────────────┐
│                             │  ← مربّع، تعبئة --store-well، بلا حشوة
│          الصورة             │
└─────────────────────────────┘
العنوان (رملي 16)
850 د.إ (ذهبي 16) · 50ml (رملي/60 14)
```

- `sm:grid-cols-2 lg:grid-cols-3` · فجوة 24px أفقياً / 48px رأسياً.
- Hover: `scale-[1.02]` على الصورة + العنوان يصير ذهبياً. **لا تدرّج، لا نص مخفي**.

## 6. صفحة القطعة `/products/[handle]`

```
h1 ذهبي 36 · سطر الحضارة/النوع رملي/60        ← على الأرضية

┌─ لوحة الصورة (7fr) ─┐  ┌─ لوحة الشراء (5fr) ────────┐

│                     │  ├────────────────────────────┤
```

## 11. ما يتغيّر عن النسخة الحالية (المراحل 2–4)

| الآن | يصبح |
|---|---|
| بطاقات ورقية `bg-sand` بنص كحلي | لوحات شعرية بنص رملي |
| فواصل `border-dotted` | `1px solid var(--store-rule)` |
| بطاقة ردّ مائلة `-rotate-2` | لوحة عادية، بلا ميل |
| بطاقة تعليق السعر (swing tag) | لوحة الشراء |
| `bg-sand/[0.04] p-3` كـmat | `--store-well` بلا حشوة |
| أزرار كحلية فوق رمل | ذهبي أساسي / outline ثانوي |
| صف فلاتر نصّي للمجموعة/الحضارة/النوع | تبويبات نوع + سطر ثانوي للحضارة/المجموعة |
| `Store.facts` بعناوين `text-h3` ذهبية | صف شعري: قيمة ذهبية + تسمية رملي/60 |

**يبقى كما هو**: الفكرة (سجل الإصدارات)، النسخ، بنية المسارات، الهيدر، الجدار المسماري، الفوتر، أرقام الصفحات، منطق الفلترة والتحقق.

## 13. الجوال وRTL

- خصائص منطقية فقط: `ms/me/ps/pe/start/end` — لا `left/right`.
- نقاط الانكسار: `sm` ثم `lg` (تذكير: `md` = 64rem = 1024px في هذا المشروع).
- كل هدف لمس ≥ 44×44 (بما فيها `×` حذف البند وسهم الفرز).
- التبويبات على الجوال: تمرير أفقي + `snap` + تلاشي حواف بـ`mask-image`.
- لا سكريم كحلي فوق صورة على الجوال؛ النص فوق الصور يستخدم `.on-photo` الموجود.

## 14. ما يحتاجه الـBackend (Medusa)

| المطلوب | التغيير |
|---|---|
| عدّادات التبويبات | `facets.types[{code,count}]` في `GET /store/threeweeq/products` — استعلام `GROUP BY product_type` واحد (بلا 7 نداءات) |
| الفرز بالسعر | `?order=newest\|price_asc\|price_desc`: يُبنى المنتج ثم يُرتّب في الـroute ثم يُقصّ حسب `limit/offset` (الكتالوج صغير؛ مع حدّ أمان 500) |
| الترتيب الافتراضي | يبقى `p.created_at desc` |

> إن تعذّر تشغيل Medusa: التبويبات تعمل بلا أرقام (يُخفى العدّاد)، والفرز يظهر خيار «الأحدث» فقط.

## 17. قرارات مطلوبة قبل التنفيذ

1. **عمق الاستبدال**: كل البطاقات الورقية → لوحات شعرية (نعم = الأقرب للصورة) أم نُبقي الرملي للقطع «الورقية» فقط (الإيصال/الفاتورة)؟
2. **رقم الإصدار**: نحفظه كسطر صغير على الحدّ العلوي للقطعة، أم نحذفه تمامًا؟
3. **العدّادات**: ننفّذ facets في Medusa الآن، أم نطلق التبويبات بلا أرقام؟
4. **الفرز**: قائمة `<select>` أصلية (أنصح) أم صفّ روابط نصّية؟
5. **الشريط المثبّت**: تلتصق التبويبات تحت الهيدر عند التمرير؟
