# خطة المتجر — «واجهة كاملة» على غرار VIVA (v3)

> **المرجع**: لقطة متجر `VIVA LIVING` الكاملة (شريط إعلان → هيدر → تبويبات → هيرو → فئات → منتجات → عروض → شهادات → نشرة → ثقة → فوتر).
> **المطلوب**: نفس **البنية والكثافة والمكوّنات**، بألوان 3WEEQ وخطوطها وهويتها.
> **يُلغى**: تحليل v2 (لقطة الدفع) كلغة عامة للمتجر. يبقى منه فقط مواصفات صفحة الدفع وحقولها.

---

## 0. تصحيح المسار

اللقطة السابقة كانت صفحة دفع واحدة، فاستنتجت لغة «الوثيقة» (لوحات شعرية، استدارة صفر). اللقطة الحالية تُظهر **واجهة متجر تجارية كاملة**، وهي المرجع الصحيح. الفرق ليس تجميلياً: المرجع **كثيف، دائري، متعدّد الأقسام، ويقود بالصور** — لا بالفراغ.

## 3. أين تُطبَّق

`/products` هي مدخل المتجر الوحيد → تصبح **واجهة المتجر الكاملة**: الأشرطة 1–11 ثم كتالوج كامل (تبويبات + بحث + فرز + شبكة + ترقيم) في الأسفل.

```
/                    → تسويقي (لا يُلمس)
/products            → واجهة المتجر + الكتالوج        ← العمل الأكبر
/products/[handle]   → صفحة القطعة (نفس اللغة)
/collections         → المجموعات (نفس اللغة)
/cart /checkout      → نفس اللغة (بطاقات مستديرة بدل اللوحات الشعرية)
```

**لا نضيف صفحة رئيسية للمتجر**: المسار `/` محجوز للتسويقي داخل نفس مجموعة الـlocale، وأي `(store)/page.tsx` سيصطدم به.

## 8. RTL

- كل الخصائص منطقية (`ms/me/ps/pe/start/end`)؛ لا `left/right` إلا لتحويلات `translateX` في التمرير (تُعكس بإشارة `isRtl`).
- أسهم التمرير تنعكس اتجاهياً؛ أيقونة «التالي» تشير يساراً في RTL.
- حقل البحث: الأيقونة في بداية السطر، زر البحث في نهايته.

## 12. قرارات مطلوبة

1. **الأرضية**: (أ) كحلية + بطاقات شفافة رملية + أحواض صور رملية *(الأنصح: استمرارية مع الموقع)* — (ب) رملية + نص كحلي *(أقرب حرفياً للمرجع)* — (ج) هجينة: أشرطة كحلية + شريط محتوى رملي.
2. **الاستدارة**: `12px` كما في المرجع *(الأنصح)*، أم `0` حفاظاً على حدّة العلامة؟
3. **الشارات**: «إصدار محدود» فقط، أم نضيف «آخر 3 قطع» عند نفاد المخزون؟
4. **الشهادات**: هل لديك 3 اقتباسات حقيقية (اسم + مدينة + نص)؟ وإلا يُخفى القسم.
5. **الكتالوج**: يبقى داخل `/products` أسفل الأشرطة *(الأنصح)*، أم صفحة `/shop` مستقلة؟
